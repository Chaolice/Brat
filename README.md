# What is Brat?

Brat is a chromium web browser companion that <sub>forces</sub>... encourages you to stay focused on your tasks.

## How does it work?

Set what websites are too distracting, and Brat will make sure you face consequences when you allow yourself to wander there.

# Brat **will chomp** your distractions away.


## Chrome Installation

1. Download the .zip file.
2. Extract the .zip file.
3. Visit [chrome extensions menu](chrome://extensions/) (chrome://extensions/).
4. On the top right, enable developer mode.
5. On the top left, click _load unpacked_. Then navigate to the extracted folder.
6. There you go! Your Brat is ready!
